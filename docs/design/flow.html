鸣潮启动器 · 完整逻辑

白色为必经步骤 · 右侧为分支结果
01打开 App
界面立即出现，但什么都不改
02申请 Shizuku
只申请授权，不碰任何系统设置
授权成功 → 分辨率可用
未授权 → 跳过分辨率与导航
方向控制仍可正常使用
03选择屏幕分辨率
原生 / 高清 / 4K 三选一
未选择 → 启动按钮灰色禁用
04点「启动游戏」
按钮变主色，开始执行
05挂方向控制悬浮窗
1×1 透明窗口，写在最上层
失败自动重试 3 次
成功 → 继续下一步
3 次全失败 → 弹窗「重试 / 取消」
游戏不启动，屏幕未做任何改动
06改分辨率 + 导航
wm size / wm density / 三键导航
仅在 Shizuku 已授权时执行
未授权 → 跳过，日志注明「无 Shizuku」
07拉起鸣潮
悬浮窗已就位后才启动
08退出还原
划掉启动器 / 点「还原显示」
移除悬浮窗 + 恢复分辨率、密度、导航
进程被杀 → 下次打开自动补还原
用户操作 程序执行 退出阶段 失败分支
